# 链接器配置修复说明

## 问题描述

编译时出现链接错误：
```
Error: L6406E: No space in execution regions with .ANY selector matching ...
```

**根本原因**：虽然MCU型号已改为STM32F407ZGT6，但链接器配置中RAM大小仍为128KB，而ZGT6需要192KB。

## 已修复的配置

### 1. 链接器脚本 (`MDK-ARM/project/project.sct`)
```sct
RW_IRAM1 0x20000000 0x00030000  {  ; RW data (192KB for STM32F407ZGT6)
```

### 2. 项目文件 - CPU配置 (`MDK-ARM/project.uvprojx`)
```xml
<Cpu>IRAM(0x20000000,0x00030000) ...</Cpu>
```

### 3. 项目文件 - IRAM配置 (`MDK-ARM/project.uvprojx`)
```xml
<IRAM>
  <StartAddress>0x20000000</StartAddress>
  <Size>0x30000</Size>  <!-- 192KB -->
</IRAM>
```

### 4. 项目文件 - OCR_RVCT9配置 (`MDK-ARM/project.uvprojx`)
```xml
<OCR_RVCT9>
  <StartAddress>0x20000000</StartAddress>
  <Size>0x30000</Size>  <!-- 192KB -->
</OCR_RVCT9>
```

### 5. 链接器数据地址范围 (`MDK-ARM/project.uvprojx`)
```xml
<DataAddressRange>0x20000000 0x00030000</DataAddressRange>
```

### 6. 指定使用Scatter文件 (`MDK-ARM/project.uvprojx`)
```xml
<ScatterFile>project\project.sct</ScatterFile>
```

## 重要提示

**如果Keil重新生成链接器脚本**：
- Keil可能会在编译时自动重新生成`project.sct`文件
- 如果编译后RAM配置又变回128KB，需要：
  1. 在Keil中：`Project -> Options for Target -> Linker`
  2. 取消勾选 `Use Memory Layout from Target Dialog`
  3. 勾选 `Use Scatter File`，并指定 `project\project.sct`
  4. 或者在 `Target` 标签页中直接修改 `IRAM1` 大小为 `0x00030000`

## 验证方法

编译成功后，检查生成的map文件：
- 打开 `MDK-ARM/project/project.map`
- 搜索 `RW_IRAM1` 或 `Execution Region RW_IRAM1`
- 确认大小为 `0x00030000` (192KB)

## 如果问题仍然存在

1. **清理项目**：
   - 在Keil中：`Project -> Clean Targets`
   - 删除 `MDK-ARM/project` 目录下的所有 `.o` 文件

2. **重新编译**：
   - `Project -> Rebuild all target files`

3. **检查Keil设置**：
   - `Project -> Options for Target -> Target`
   - 确认 `IRAM1` 的 `Start:` 为 `0x20000000`，`Size:` 为 `0x00030000`

4. **手动指定Scatter文件**：
   - `Project -> Options for Target -> Linker`
   - 勾选 `Use Scatter File`
   - 指定路径：`project\project.sct`
