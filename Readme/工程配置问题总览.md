# 工程配置问题总览（CubeMX / MDK 配置类）

本文件对 `Readme/` 目录下与 CubeMX、外设复用、DMA、RAM/链接器 等相关的问题做一个“快速总览”。  
详细推理过程请参见对应的单独文档。

---

## 一、CubeMX 红字与配置差异

| 问题现象 | 核心原因 | 关键修改点 | 详细分析 |
|---------|----------|------------|----------|
| CubeMX 中部分外设/引脚出现红色标记 | 复用冲突 / 旧 ioc 配置与当前工程不一致 | 对照参考工程 ioc，统一 AF 选择并清理未用外设 | `CubeMX红色标记原因分析.md` |
| Master 与 `1` 文件夹工程配置不一致 | 两套 ioc/工程模板混用，部分外设参数不同 | 明确以当前 Master 为主，对比差异逐项确认 | `Master与1文件夹配置差异详细对比.md`、`用1文件夹ioc配置master导致失效原因分析.md` |
| USART1 模式下拉菜单红色 | 复用/时钟源配置异常 | 检查 AF 选择、波特率时钟源，按文档修复 | `USART1模式下拉菜单红色标记分析.md` |

## 二、I2S2 / SDIO / DMA / 串口冲突类

| 问题现象 | 根因简述 | 解决思路 | 详细文档 |
|----------|----------|----------|----------|
| I2S2 看似配置正确但实际不工作 | I2S2 / I2S2ext / 时钟极性等参数不匹配 WM8978 | 统一 I2S2/I2S2ext 配置，确保主从/极性/数据宽度与 WM8978 手册一致 | `I2S_WM8978问题分析与解决方案.md` |
| I2S2 被“自动禁用”或不输出时钟 | SDIO、I2S2、串口等外设共享同一组引脚和时钟源导致冲突 | 调整复用关系，避免 SDIO/I2S2/USART 同时占用有冲突的 AF；必要时牺牲部分调试串口 | `I2S2禁用问题分析.md`、`I2S2禁用问题全面分析.md` |
| 配置了 DMA 但仍然不工作 | DMA 通道/Stream 选错，或 NVIC 未使能中断 | 按参考手册重新选择正确 Stream/Channel，打开中断并确认优先级 | `DMA配置后仍不工作原因分析.md`、`添加DMA配置后仍不工作问题排查.md` |
| 配 SDIO + I2S2 后串口输出失效 | 外设复用导致串口 TX/RX 引脚被改为其他功能 | 回退/调整对应引脚的 AF 配置，必要时更换串口引脚 | `SDIO_I2S2配置导致串口输出失效问题分析.md`、`Master串口输出失效问题分析.md` |
| 配 SDIO + I2S2 后按钮点击无反应 | EXTI 引脚与 SDIO/I2S2 复用冲突，被改成其他模式 | 将按键引脚重新设为 GPIO 输入+EXTI，避免与 SDIO/I2S2 争用 | `SDIO_I2S2配置导致按钮点击失效问题分析.md`、`按钮点击串口输出实现机制分析.md` |

## 三、RAM / 链接器 / 内存使用

| 问题现象 | 根因简述 | 解决思路 | 详细文档 |
|----------|----------|----------|----------|
| 工程偶发 HardFault / 播放功能工作不稳定 | Heap/Stack 设置偏小，音频缓冲 + FATFS + 其他动态内存逼近上限 | 提升 Heap/Stack，分析动态分配高峰时刻的内存需求 | `内存使用详细分析.md`、`音频播放功能实现方案.md` |
| 工程链接失败或提示内存段溢出 | 链接脚本/MDK Scatter 文件未正确匹配 F407 的 RAM/Flash 布局 | 修正 RAM/Flash 区段大小与起始地址，重新分配堆栈 | `RAM配置修复说明.md`、`链接器配置修复说明.md` |
| v1.0 录音机工程与当前工程行为差异 | 链接器配置、堆栈、地址映射不同，导致相同代码行为不同 | 对比 v1.0 Scatter，与当前工程统一 RAM/Flash 布局 | `v1.0录音机实现全面分析.md` |

推荐的最终内存配置结论（结合音频播放与 LVGL，占用见 `内存使用详细分析.md`）：

- Heap：40–48KB（根据 `内存使用详细分析.md` 与 `音频播放功能实现方案.md` 的计算）
- Stack：16KB 左右

## 四、如何使用这些文档

- 如果你在 **CubeMX 里看到外设红字 / 引脚冲突**：优先看本文件第 1 节，然后跳转对应 `CubeMX*` 和差异分析文档。
- 如果你在 **打开 SDIO/I2S2 后发现串口/按键/音频异常**：先看第 2 节表格中的对应条目，然后去看详细排查步骤。
- 如果你遇到 **莫名其妙的内存相关崩溃/链接错误**：看第 3 节的链接，确认当前工程的 Heap/Stack 与链接器配置是否已经按“最终结论”修正。
